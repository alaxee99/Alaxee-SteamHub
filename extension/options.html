01

添加游戏

填写 Steam AppID 和游戏名称，建立独立配置档案。

当前适配器：Steam 社区市场。AppID 用于区分游戏，物品名称使用 Steam 原始 market_hash_name，不做模糊归一化。

02

录入翻译词条

可逐条输入物品代码，也可以在下方批量导入游戏数据包。

market_hash_name 用于精确匹配 Steam 页面；游戏数据库物品 ID / Code 用于记录它对应的游戏内数据项；数据源名称用于追溯词条出处。三者用途不同，不要互相替代。

同一游戏、同一物品和同一语言的再次录入会更新原词条。不同游戏即使物品原名相同，也不会互相覆盖。

03

从公开 JSON / CSV 目录转换词库

只转换拥有精确 Steam market_hash_name 与译文的记录。相同键同译文会合并；同一键出现不同译文或不同来源 ID 时整组排除并报告冲突，不做模糊匹配。普通 Wiki HTML 页面不是 JSON / CSV，需要单独的页面解析适配器。
